1. Estructura y Preguntas

En coreano, el verbo SIEMPRE va al final.

Sujeto + Tiempo + Lugar + Objeto + Cantidad + Verbo

¿Palabras para Preguntar?

  • 뭐 - ¿Qué / Cuál?
  • 무슨 - ¿Qué tipo? (Sust)
  • 언제 - ¿Cuándo?
  • 몇 시 - ¿A qué hora?
  • 며칠 - ¿Qué fecha?
  • 누구 - ¿Quién?
  • 어디 - ¿Dónde?
  • 몇 - ¿Cuántos?
  • 얼마 - ¿Cuánto cuesta?

2. Partículas (Pegamento)

  • 은 / 는 (Tema/Sujeto): Común, verdades absolutas.
  • 이 / 가 (Sujeto): Menos común. Se usa para verbos de estado, tener/estar, o "deme por favor" (주세요).
  • 을 / 를 (Objeto Directo): Lo que recibe la acción (Responde al verbo).
  • 에 (Lugar / Tiempo): Dirección, destino o tiempo.
  • 에서 (Lugar de Acción): Dónde OCURRE una acción.
  • 도 (También): Sustituye a 은/는 y 을/를. Ej: 타니아 씨도 공부해요.
  • 하고 / (이)랑 / 와/과: Y (Para unir sustantivos).
  • 그리고: Y (Punto y aparte, une oraciones).
  • (으)로: Hacia, con, en. Sustituye a 에. Palabras clave: 시간이, 얼마나, 걸려요, 쯤.

3. Conjugación y Pasado

Primero siempre se elimina el 다 del verbo base.

Presente: 1. Termina en ㅏ / ㅗ → 아요
2. Termina en otra vocal → 어요
3. Termina en 하다 → 해요
Tiempo Pasado: Sigue la misma regla anterior pero con: 았어요 / 었어요 / 했어요.

4. Verbos Irregulares

  • ㄷ → Se elimina por ㄹ
  • ㅂ → Se elimina por 오/우
  • ㅡ → Se elimina si no tiene consonante final (Toma 아요/어요 de la vocal anterior).
  • 르 → Se elimina por ㄹ y se duplica.

6. Ubicaciones

Estructura: Lugar + Ubicación + 에 / 에서

7. Expresiones y Contadores

  • Ser (Es): 이에요 (Consonante) / 예요 (Vocal).
  • Tener/Haber/Estar: 있어요 (Hay) / 없어요 (No hay).
  • Gustar: 좋아해요 (Me gusta) / 싫어해요 (No me gusta).
  • Negación: 안 + Verbo (Ej: 공부 안 해요).
  • Quiero... : Verbo sin 다 + 고 싶어요 (Pasado: 고 싶었어요).
  • Voy a hacer... : Vocal + 러 가요 / Consonante + 으러 가요.
  • Instrucción: 으세요 (Haz) / 지 마세요 (No hagas).
  • Esto/Eso/Aquello: 이게(Esto), 그게(Eso), 저게(Aquello). 여기(Aquí), 거기(Ahí), 저기(Allá).

Contadores Básicos

Sustantivo + Número (Nativo) + Contador

개: Objetos 명: Personas 마리: Animales 권: Libros/Hojas 병: Embotellados 대: Grandes/Autos 장: Boletos/Hojas
